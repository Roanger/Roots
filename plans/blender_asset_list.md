## Notes & Conventions

- Format: **`.blend`** files imported directly into Godot 4 (requires Blender path set in `Editor → Editor Settings → Filesystem → Import → Blender → Blender Path`)
- Origin point: base of object (for ground-placed assets) or center of mass
- Scale: match existing scene units (1 unit = 1 metre)
- LODs: create at least 2 LOD levels for large/complex meshes
- Naming: `snake_case` matching the corresponding `ItemDatabase` / `AnimalData` resource IDs where applicable
